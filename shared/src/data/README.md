# Static data

- `parkings.osm.json` is generated by `pnpm data:parkings` from OpenStreetMap (ODbL). Do not edit it by hand.
  To correct a parking, fix the data upstream or add a documented override file.
- Never add invented parkings, prices or occupancy here. Demo occupancy goes in a separate,
  clearly named `*.simulated.json` file with `quality: "simulated"`.
